# IOC Collections

This folder contains Indicators of Compromise (IOCs)
identified during malware analysis,
campaign research, and threat intelligence activities.

The IOC data is maintained in a structured format
for cybersecurity research, detection,
and defensive security analysis.

---

# IOC Categories

- IP Addresses
- Domains
- URLs
- File Hashes
- Registry Keys
- File Names
- Process Names
- Mutexes
- Services
- Scheduled Tasks

---

# Common IOC Examples

| IOC Type | Example |
|----------|---------|
| IP Address | 192.168.1.10 |
| Domain | malicious-site.com |
| URL | https://fake-login.com |
| SHA256 Hash | e3b0c44298fc1c149afbf4c8996fb924 |
| Process Name | powershell.exe |
| Registry Key | HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run |

# Detection Opportunities

Security teams can detect IOCs through:

- Suspicious outbound connections
- Unusual PowerShell activity
- Unknown startup entries
- Registry persistence activity
- Malicious hash detection
- Suspicious DNS requests
