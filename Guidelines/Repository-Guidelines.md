# Repository Guidelines

## Purpose

This repository is maintained for cybersecurity internship
research, malware analysis, threat intelligence collection,
weekly reporting, and structured documentation.

---

# Folder Structure Rules

- Maintain proper folder hierarchy
- Store files in their respective folders
- Avoid duplicate reports and screenshots
- Keep repository clean and organized

---

# Naming Convention

Use meaningful file names.

## Examples

- S0691_Whirlpool.md
- Week-01_Report.md
- Whirlpool_IOCs.md
- Lazarus_AttackChain.png

---

# Documentation Standards

Every report should contain:

- Title
- Description
- MITRE ATT&CK Mapping
- Execution Method
- Persistence Techniques
- Defense Evasion
- IOC Collection
- Detection Methods
- References

---

# Markdown Rules

Use proper markdown formatting:

## Headings

# Heading 1
## Heading 2
### Heading 3

## Lists

- Item 1
- Item 2

## Tables

| Technique | ATT&CK ID |
|-----------|-----------|
| Phishing | T1566 |

---

# Screenshot Guidelines

- Use clear screenshots only
- Avoid blurry or cropped images
- Store screenshots in Screenshots folder
- Use meaningful screenshot names

Example:
- MITRE_Whirlpool.png
- VirusTotal_Report.png

---

# Weekly Progress Rules

Each weekly folder should contain:

- Report.md
- Tasks.md
- Research-Notes.md

---

# Research Standards

Research must include:

- Malware description
- Threat actor association
- ATT&CK techniques
- IOC analysis
- Detection methods
- Mitigation techniques

---

# Important Note

Documentation should remain structured,
clear, and professionally maintained.

Documentation is survival.
