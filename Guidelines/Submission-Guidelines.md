# Submission Guidelines

## Submission Format

Reports can be uploaded in:

- Markdown (.md)
- PDF (.pdf)
- DOCX (.docx)

---

# Required Report Sections

Every report must include:

- Title
- Description
- Technical Analysis
- MITRE ATT&CK Techniques
- Screenshots
- IOC Collection
- References

---

# Folder Requirements

- Maintain proper folder structure
- Keep weekly reports organized
- Store screenshots separately
- Avoid random files in repository

---

# File Naming Rules

Use professional file names.

## Correct Examples

- S0691_Whirlpool.md
- Week-01_Report.md
- IOC_Report.pdf

## Incorrect Examples

- finalfinal.docx
- malware123.md
- screenshot1.png

---

# Weekly Submission Rules

Each week should contain:

- Weekly report
- Research notes
- Malware analysis progress
- IOC updates

---

# Final Submission

Final submission folder should contain:

- Final Report
- Presentation
- Documentation
- Research Summary

---

# Important

Incomplete or poorly organized documentation
may affect evaluation quality.
