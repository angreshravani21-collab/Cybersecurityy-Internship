# Diagrams

This folder contains cybersecurity diagrams,
attack flow representations,
MITRE ATT&CK mappings,
and malware operation visuals
created during the internship.

The diagrams are used to simplify
technical concepts and provide
visual understanding of cyber attacks,
malware behavior, and defensive strategies.

---

# Diagram Categories

- Attack Flow Diagrams
- Malware Lifecycle Diagrams
- MITRE ATT&CK Mapping
- Command & Control (C2) Flow
- Network Attack Flow
- Phishing Attack Chains
- Data Exfiltration Flowcharts
- Incident Response Workflow

---

# Purpose

The diagrams are created for:

- Visual threat analysis
- Malware behavior understanding
- Attack chain visualization
- Security awareness
- Threat intelligence documentation
- Technical presentations
- Research documentation

---

# Common Diagram Examples

| Diagram Type | Description |
|--------------|-------------|
| Attack Flow | Shows stages of cyber attack execution |
| Malware Lifecycle | Displays malware infection stages |
| MITRE Mapping | Visual ATT&CK technique mapping |
| Phishing Flow | Represents phishing attack sequence |
| C2 Communication | Displays attacker-to-victim communication |
| Network Diagram | Shows lateral movement and propagation |
