# Software Research

This folder contains summarized research and technical analysis
of malware, post-exploitation frameworks, loaders, wipers,
and command-and-control (C2) tools assigned during the internship.

The reports are maintained in a concise and structured format
for quick understanding, threat analysis, MITRE ATT&CK mapping,
IOC identification, and defensive study purposes.

---

# Research Includes

- Malware Description
- Threat Actor Association
- Supported Platforms
- MITRE ATT&CK Techniques
- Persistence Techniques
- Defense Evasion
- IOC Collection
- Detection & Mitigation
- References & Sources

---

# Purpose

The purpose of this folder is to provide simplified,
organized, and summarized cybersecurity research
documentation for educational and internship use.
